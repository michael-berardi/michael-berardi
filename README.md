# Michael Berardi

Software engineer and studio operator building local-first AI tools, cross-platform desktop software, and durable web systems.

I run [Liberty Design Studio](https://libertydesign.studio/), where I design, ship, and operate software and web systems for businesses with real operational constraints. My open-source work focuses on AI agent infrastructure: browser and desktop automation, knowledge systems, and private on-device applications.

## Selected work

- **[Retex](https://github.com/michael-berardi/retex)** — a local-first Markdown knowledge engine and machine-readable CLI for people and agents.
- **[OverSeer Browser](https://github.com/michael-berardi/overseer-browser)** — model-agnostic browser automation for Chromium, with a local-first security boundary.
- **[UltraTerm Computer Use](https://github.com/michael-berardi/ultraterm-computer-use)** — local desktop automation for MCP-capable agents on macOS, Linux, and Windows.
- **[UltraVox Light](https://github.com/michael-berardi/ultravox-light)** — private, on-device transcription across macOS, Windows, and Linux.

Across these projects: small dependency graphs, explicit security boundaries, and software that remains understandable after the demo.
